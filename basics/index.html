JS Before React

all you need to know in JavaScript before React

01

Variables

const holds a fixed value and can't be reassigned — it's the most common in React. let allows the value to change. var is the old way and should be avoided.

const name = "wael";
let age = 23;

console.log(name, age);
02

Objects

An object groups related data as key: value pairs. Destructuring lets you pull specific values out in one line — used constantly in React props and hooks.

const person = {
    name: "wael",
    age: 23,
    isStudent: true,
};

const { name: personName, age: personAge } = person;
console.log(personName, personAge);
03

Arrays

An array is an ordered list. Array destructuring works the same way as object destructuring — assign array items to variables by position. React's useState uses this pattern.

const people = ["wael", "ahmed", "ali"];

const [first, second] = people;
console.log(first, second);
04

Functions

The traditional function keyword works everywhere. Arrow functions are shorter and are the standard in React components and callbacks. If the body is a single expression, you can drop the braces and return.

function greet(name) {
    return "Hello, " + name;
}

const sayHi = (name) => {
    return "Hi, " + name;
};

const greetShort = (name) => "Hi, " + name;

console.log(greet("wael"));
console.log(sayHi("ahmed"));
console.log(greetShort("ali"));
05

Conditionals

Standard if/else works for logic outside JSX. The ternary operator (condition ? a : b) is the go-to inside JSX because it's a single expression, not a statement.

const userAge = 20;

if (userAge >= 18) {
    console.log("Adult");
} else {
    console.log("Not adult");
}

const status = userAge >= 18 ? "Adult" : "Not adult";
console.log(status);
06

Array Methods

map() transforms every element and returns a new array — essential for rendering lists in React. filter() returns only elements that pass a condition. reduce() collapses the array into a single value like a sum.

const numbers = [1, 2, 3, 4, 5];

const doubled = numbers.map((n) => n * 2);
console.log("map:", doubled);

const evens = numbers.filter((n) => n % 2 === 0);
console.log("filter:", evens);

const sum = numbers.reduce((total, n) => total + n, 0);
console.log("reduce:", sum);
07

Spread Operator

The spread operator (...) copies arrays or objects without mutating the original. React state must never be mutated directly — spread is how you create updated copies.

const original = [1, 2, 3];
const copy = [...original, 4, 5];
console.log("spread array:", copy);

const user = { name: "wael", age: 23 };
const updatedUser = { ...user, age: 24 };
console.log("spread object:", updatedUser);
08

Template Literals

Template literals use backticks instead of quotes and let you embed variables with ${}. Much cleaner than concatenating strings with +.

const userName = "wael";
const age = 23;

const greeting = `Hello, ${userName}! You are ${age} years old.`;
console.log(greeting);
09

Modules — Export & Import

export makes a function or variable available to other files. import brings it in. Every React component file uses this — a component is just an exported function.

export const sayHello = (name) => `Hello, ${name}`;

import { sayHello } from "./utils.js";
10

Async / Await / Fetch

async marks a function as asynchronous. await pauses execution inside it until the promise resolves. fetch() sends an HTTP request to an API — this is how React apps load data from a server.

async function getUser() {
    const response = await fetch("https://jsonplaceholder.typicode.com/users/1");
    const data = await response.json();
    console.log("fetch result:", data.name, data.email);
}

getUser();
